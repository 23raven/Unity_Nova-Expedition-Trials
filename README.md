# Nova Expedition Trials

A small story-driven adventure game developed with Unity

---

# Features
- Third-person exploration gameplay
- Collectible Stellar Pearls
- Enemy chase mechanics
- Sprint & stamina system
- Asteroid avoidance mini-game
- Visual Novel style dialogue scenes
- Voice acting and sound effects
- Credits sequence with music
